# Zaika Indian Restaurant Landing Page

A beautiful, responsive landing page for Zaika Indian Restaurant featuring a rich red and gold theme, showcasing authentic Indian cuisine.

## Features

- **Hero Section** with captivating tagline and call-to-action buttons
- **Menu Section** displaying authentic Indian dishes with prices
- **About Our Chefs** section highlighting culinary expertise
- **Testimonials Section** with customer reviews and ratings
- **Table Booking/Contact Form** with client-side validation
- **Rich Red and Gold Theme** throughout the design
- **Fully Responsive Layout** - works on mobile, tablet, and desktop
- **Smooth Animations** and interactive elements
- **Accessibility Features** including ARIA labels and proper contrast

## Tech Stack

- HTML5
- CSS3 (CSS Variables, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Lato)

## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavpadige4/zaika-indian-restaurant-landing-page-v2.git
   ```

2. Open `index.html` in your browser to view the landing page locally.

## Deployment

This site is deployed using Netlify. To deploy your own version:

1. Push this repository to GitHub
2. Connect your GitHub repository to Netlify
3. Set build command to: `none` (static site)
4. Set publish directory to: `/` (root)
5. Trigger deploy
